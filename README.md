# Карточки слов / Word Cards

Android-приложение для изучения слов по карточкам с интервальными повторениями.
Русскоговорящие учат английский, англоговорящие — русский. Интерфейс на русском и английском.

*English: an Android flashcard app with spaced repetition. Russian speakers learn English, English speakers learn Russian. The interface is available in both languages (see the short summary at the end).*

## Возможности

- **Урок дня.** Фиксированный набор новых слов проходится по четырём этапам подряд: Карточки → Выбор → Ввод → Аудио. Перед ним — повторение старых слов по графику. День и серия засчитываются только после завершения урока; незаконченный урок ждёт, прогресс сохраняется после каждого ответа.
- **Интервальные повторения** (модификация SM-2, как в Anki): кнопки «Снова / Трудно / Хорошо / Легко» с подписью, когда слово вернётся. Расписание обновляется один раз на слово — на этапе «Карточки».
- **Словарь на 19 044 слова**, 6 уровней (A1–C2) по частотности, у 84 % слов есть пример предложения с переводом.
- **Гибкий выбор, что учить.** Новые слова можно брать из любого уровня или из всех. Экран «Уроки» у каждого уровня: пройти любой урок заново, отметить урок, диапазон уроков или весь уровень как известные, сбросить их и учить с начала.
- **Два изучаемых языка.** Можно учить английский или русский: озвучка, распознавание речи и подсказки подстраиваются. Для русских слов отображаются знаки ударения.
- **Озвучка** слов и предложений (синтезатор речи Android) и **голосовой ввод** в режимах «Ввод» и «Аудио» (окно распознавания речи Google).
- **Дополнительные тренировки:** «Только по графику», «Пройденное», «Сложные».
- Словарь с поиском, избранным и отметкой «знаю»; статистика; серия дней; ежедневное напоминание; импорт собственных слов из CSV.
- Экран «Как это работает» с правилами для пользователя, приветствие при первом запуске.
- Фильтр нецензурной лексики в словарях, примерах, вариантах ответа и при импорте.
- Окно оценки: на 10-м запуске и далее каждые 50 запусков, пока оценка не поставлена (4–5 звёзд — RuStore, 1–3 — письмо разработчику).
- Только портретная ориентация, светлая и тёмная тема, динамические цвета Material You.

## Технологии

Kotlin · Jetpack Compose (Material 3) · Room · DataStore · WorkManager · Navigation Compose · AppCompat (смена языка).
`minSdk 26`, `targetSdk 34`, пакет `com.semenenko.wordcards`.

## Сборка

1. Установите Android Studio (JDK 17).
2. Откройте папку проекта (File → Open) и дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на устройстве или эмуляторе (Run).

При первом запуске приложение один раз загружает словарь из `assets` в базу данных.

## Формат словаря и свои слова

Файл UTF-8, одна строка — одно слово, поля разделены `;`:

```
english;русский;транскрипция;пример EN;пример RU
```

Обязательны первые два поля, строки с `#` игнорируются. В русских словах и предложениях допускаются знаки ударения (U+0301). Свои слова добавляются в приложении: Настройки → «Свои слова (импорт CSV)».

## Пересборка словаря (необязательно)

Скрипты лежат в `tools/` и запускаются оттуда (`pip install wordfreq eng-to-ipa lemminflect better-profanity`):

1. `build_dictionary.py` — первичная сборка слов.
2. `enrich_dictionary.py` — очистка нецензурной лексики, примеры предложений, ударения.

Нужные данные (корпус предложений и база OpenRussian) в репозиторий не входят, подробности — в `tools/README.txt`.

## Конфиденциальность

Приложение не запрашивает доступ в интернет, не собирает аналитику и не отправляет данные: прогресс хранится на устройстве. Озвучку и распознавание речи выполняют системные сервисы Android и Google. Оценка 1–3 звезды открывает почтовое приложение с готовым письмом — отправляет его сам пользователь.

## English summary

**Word Cards** teaches vocabulary with flashcards and spaced repetition (SM-2). A daily lesson takes a fixed set of new words through four steps — Cards → Choice → Typing → Listening — after a quick review of due words; the streak counts only completed lessons. The built-in dictionary has 19,044 words in six frequency-based levels (A1–C2), with example sentences, pronunciation (TTS) and voice input. You choose what to learn: new words from any level, re-study any lesson, mark lessons or levels as known, or reset them. Russian speakers learn English and English speakers learn Russian; the interface is available in both languages. Build: open the folder in Android Studio (JDK 17), sync Gradle and run `app`. Data: OpenRussian (CC BY-SA 4.0), Tatoeba (CC BY 2.0 FR), wordfreq, CMUdict.
